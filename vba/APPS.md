# CaelusOS 还能再做什么 App

判断标准：现有架构里，一个「App」= 若干张幻灯片（界面）+ 命名形状（控件）+ 一段宏（逻辑）
+ 平台接口（数据）。下面按「能不能立刻做」分三档。

> 前提说明：本仓库工具目前只能改宏，**新增幻灯片**要在 Windows 版 PowerPoint 里加，
> 或先扩展工具做幻灯片注入。下面每项都标了是否需要新页面。

---

## 一档：只加宏就能做（不需要新页面）

| App | 做什么 | 实现要点 |
|---|---|---|
| **语音朗读** | 让 Star Intelligence 的回答读出来 | `CreateObject("SAPI.SpVoice").Speak(text)`，加一个「朗读」按钮绑 `AppSpeak` |
| **终端（做真）** | 第 94 页已有「终端」入口，现在只是界面 | `CreateObject("WScript.Shell").Exec("cmd /c dir")`，读 stdout 写进形状；**建议只放白名单命令** |
| **任务管理器（做真）** | 显示真实 CPU / 内存 / 磁盘 | WMI：`Win32_PerfFormattedData_PerfOS_Processor`、`Win32_LogicalDisk`，输出到形状 |
| **系统自检（做真）** | 安全模式里「设备自检」变真 | WMI + `Scripting.FileSystemObject` 取磁盘空间、内存、系统版本、字体是否已安装 |
| **便签升级** | 笔记页支持多条目 + 时间戳 | 复用 `AppLoadData/AppSaveData`，key 改成 `note_1..note_9` |
| **额度面板** | 用户能自己看还剩多少 AI 次数 | 已经写好 `PPTSec_ShowQuota`，绑到设置页按钮即可 |
| **审计查看** | 设置里看最近的调用记录 | 读 `%TEMP%\pptos_audit.log` 显示最近 20 行 |

## 二档：加一两个新页面 + 一段宏（推荐先做这些）

| App | 做什么 | 实现要点 |
|---|---|---|
| **时钟 / 天气组件** | 桌面显示当前时间、天气 | 时间用 `Now`；天气接公开 API（HTTPS，`MSXML2.XMLHTTP` 可直连）。刷新用 `DoEvents` 循环或放映时的动画触发 |
| **待办 / 日程** | 勾选式待办，跨设备同步 | 复制一页做界面，云数据 key=`todo_<yyyymmdd>`，JSON 存数组，宏解析后刷新文字 |
| **相册（做真）** | 现在「照片」是静态图，改成能换 | 已有 `SetShapeImage(shape, url)` 现成函数：把图片 URL 存云数据，读回来直接 `Fill.UserPicture` 换图 |
| **主题商店** | 下载主题包，一键换肤 | 主题 = 一段 JSON（主题色、字体、壁纸 URL）。宏解析后批量改形状填充/字体；公共数据 `theme_list` 放主题清单 |
| **应用商店** | 系统内浏览/更新 CaelusOS 应用 | 接现有 `/app/api/public` 拉应用清单 + `download_url`；和 download.caelus.top、App 仓库天然联动 |
| **记账本** | 简单收支记录 + 统计 | 云数据存记录，复用计算器的 `AppCalcEval` 做汇总，形状里画简易柱状图（改形状高度） |
| **通讯录（做真）** | 现在通讯录是静态文案 | 云端存联系人数组，列表用形状克隆/文字刷新 |
| **音乐播放器** | 能真放歌 | `ShellExecute` 调用系统播放器打开音频直链；或嵌 Windows Media Player ActiveX 控件 |
| **文件管理器（做真）** | 列出真实目录 | `FileSystemObject` 遍历 `C:\Users\<user>\...`，输出到形状列表；双击项 → `ShellExecute` 打开 |

## 三档：有意思但要动结构 / 依赖外部能力

| App | 做什么 | 要点 |
|---|---|---|
| **多用户桌面** | 不同 OK 账号进来是不同壁纸/主题/应用排布 | 登录后按 `uid` 拉云配置，跟着换形状。顺带把「个性化」页做成真配置项 |
| **云同步的窗口状态** | 关掉再开，窗口位置/打开的 App 都还记得 | 云数据存一份「桌面状态」JSON，登录后回放 |
| **屏幕录制 / 专注模式** | 控制中心里这两个现在只是图标 | 真录制要 Windows API（复杂）；专注模式可做「全屏 + 关通知 + 计时」的轻量版 |
| **应用商店开发者版** | 第三方开发者提交 PPT 应用 | 需要服务端（可以放在 caelus-terminal）：上传 pptm → 自动跑本仓库的 `extract` 抽宏审代码 → 签名后上架 |
| **CaelusOS 在线更新** | 增量更新，不重下 43MB | 现在整包覆盖太重；可拆「数据包 + 界面包」，用本工具重建差分包 |
| **移动端/网页版影子系统** | 让别人不用装 Office 也能看 | 把 94 页导出成网页版（截图 + 热区），CaelusOS 的界面就能在浏览器里跑演示 |

## 落地建议

1. **先做「一档」的语音朗读 + 系统自检**：改动小、演示效果直接，能立刻验证 PPTSec 这套闸门没挡正常功能。
2. **再做「应用商店」**：它是把 CaelusOS 从「一个 PPT」变成「一个平台」的关键一步，
   而且和已有的 download.caelus.top / App 仓库 / 星环、OK 账号体系能串成一条线。
3. **新增页面前先定命名规范**：形状名（`TextBox1`、`Calc_TextBox`、`UserTX`…）是宏和界面之间唯一的契约，
   建议统一成 `应用_控件_序号`，否则后面加 App 会越来越容易踩雷。
4. 每个新 App 的宏都放在**已有模块**里（工具暂不支持新增模块），如无必要别新建模块。
